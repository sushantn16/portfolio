I just got back from the performance.now() conference in Amsterdam, and it left me really inspired.

It was a great reminder that performance and sustainability go hand in hand, especially in the age of AI, where so much code is auto-generated. Writing efficient, reliable code we can trust is more important than ever.

One thought from Ines Akrap stuck with me:

> Imagine your code as a bridge. Would you drive over it?

A simple but powerful reminder to care about what we build, and to find delight in making the web better.
